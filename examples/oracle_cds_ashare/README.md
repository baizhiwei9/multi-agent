```
python examples/oracle_cds_ashare/run_demo.py
```

逐项打印 `PASS/FAIL`，退出码 0 表示链路与判定都符合预期（当前 30 项）。

## 链路

```
news/collect（CDS / 违约 / 评级下调关键词）
  → supervisor/tune（信用组权重、大事阈值）
  → assess/classify（credit_stress / bear）
  → transmit/map（事件压力 → 环节融资依赖 → A 股标的压力分
                  + 资本开支下修情景下的营收影响）
```

## 假设：A 股传导

`config/transmit/ai_ashare.json` 给每个环节一个融资依赖度与资本开支弹性，给每个标的一个敞口与 AI 收入占比：

```
severity     = min(100, 隐含PD / 30%) = 76.7
stress(环节)  = severity × financing_dependence
score(标的)   = stress × exposure            → 0-100 压力分，≥50 高 / ≥35 中高 / ≥20 中 / <20 低
营收影响(标的) = -capex_cut × capex_sensitivity × ai_revenue_share
```

跑出来（`capex_cut=10%`）：

| 环节 | 依赖 | 压力 | 营收情景 |
|---|---|---|---|
| IDC / 算力租赁 | 0.90 | 69.0 高 | -8.5% ~ -6.5% |
| 服务器 / 整机 | 0.70 | 53.7 高 | -5.0% ~ -2.2% |
| 光模块 / 光器件 | 0.60 | 46.0 中高 | -8.1% ~ -6.2% |
| PCB / 铜连接 | 0.55 | 42.2 中高 | -4.8% ~ -4.4% |
| 液冷 / 电源 | 0.45 | 34.5 中 | -2.7% ~ -1.8% |
| 电力设备 | 0.30 | 23.0 中 | -0.6% ~ -0.5% |
| 国产算力 / 信创 | 0.15 | 11.5 低 | -0.2% ~ -0.1% |

**两套数字别混着看**：压力分是"传导强度"，营收影响是"若资本开支下修 10%、
且假设的 AI 收入占比成立，营收大约少几个点"。前者不是涨跌幅，后者只到收入，
不含毛利、费用、估值变化，也不是目标价。

## 换成真实数据

- 事实：把 `fixture/news.json` 换成真实新闻源（`NewsWatchFramework(fetch=...)`）；
- 最新进展：`LATEST` 里的数要有当日报道支撑，过期就删，不留在"今日"；
- 假设：把 `financing_dependence` / `exposure` / `capex_sensitivity` / `ai_revenue_share`
  换成实测值（融资占比、收入占比、订单占比），改配置即可，不改代码；
- severity 刻度：`PD_FULL`（默认 30%）就是"多少违约概率记满分"，按自己的风险口径调；
- 情景幅度：`capex_cut` 默认 10%，可在 `transmit/map` 入参覆盖。
